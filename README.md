# Synapse

Autonomous on-chain agent on **Mantle**, built for the **Turing Test Hackathon 2026** (Agentic Economy track).

Synapse reads smart-money intelligence, reasons with a crypto-native LLM, and acts on-chain with a verifiable, on-chain-recorded track record — an agent with a memory, not a stateless bot.

## Status
🚧 Work in progress — built during the hackathon (May–June 2026).

## Planned stack
- **Perception:** Nansen on-chain data & intelligence API (smart money)
- **Reasoning:** crypto-native LLM (AltLLM / GLM)
- **Execution:** RealClaw on Mantle
- **Identity & track record:** ERC-8004
- **Always-on:** 24/7 agent loop
